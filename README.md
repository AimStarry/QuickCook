# QuickCook

QuickCook is a front-end web application designed to help home cooks discover recipes and access cooking lessons. Whether you are a beginner looking to master the basics or a pro searching for new inspiration, QuickCook provides a clean, user-friendly interface to guide your culinary journey.

## 🚀 Features

* **Recipe Discovery:** Browse a variety of curated recipes.
* **Cooking Lessons:** Step-by-step guides for various cooking techniques.
* **Subscription Plans:** Access to premium content and personalized schedules.
* **Responsive Design:** Fully optimized for different screen sizes.

## 🛠️ Tech Stack

* **HTML5:** Structure of the web pages.
* **CSS3:** Styling and layout (including minimized files for performance).
* **JavaScript:** Interactivity and front-end logic.
